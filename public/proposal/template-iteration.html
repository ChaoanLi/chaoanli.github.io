Review round

Test a claim against a primary source and record the decision that changed.

Download an editable Markdown copy ↓

Input: [candidate ID, prior round, dated copy, evidence IDs]. Claim at issue: [verbatim location]. Question: [which change could alter the disposition?]

  1. The preparer takes a checked statement from the source. Keep one correct control and change one consequential fact in a separate copy. Record the expected finding, source locator and reason in a private answer key. Keep both test items out of the live record.
  2. Give the two copies neutral labels in shuffled order. Ask an independent reader, or a fresh model session with authorized inputs, to return the location, claimed defect, supporting evidence and consequence for each. Withhold prior reviews and the answer key.
  3. Reveal the key. Record whether the reader found the planted defect and whether the correct control was falsely flagged. Track misses, false alarms and unresolved items with denominators. State whether an actual blind pass took place. A single pair checks one failure mode.
  4. Correct the live record only after verifying the primary source. Preserve the prior version, any dissent, the changed decision and the remaining uncertainty.
